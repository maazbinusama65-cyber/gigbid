# service-marketplace-backend

> provider matching site - repository for the online marketplace engagement.

## Features

- Backend services written in server-side JavaScript
- Uses **Express** (see `src/`)
- Uses **PostgreSQL** (see `src/`)
- Versioned JSON endpoints with consistent errors and pagination
- Uses **JWT authentication** (see `src/`)
- Containerised builds that run the same on every machine

## Quick start

```bash
npm install
npm run dev
```

## Layout

- `src/nodejs_service.ts`
- `src/express_service.ts`
- `src/postgres_service.sql`
