# saas-billing-portal

> customer invoicing dashboard - repository for the saas engagement.

## Features

- Uses **Next.js** (see `src/`)
- Uses **TypeScript** (see `src/`)
- Card payments, subscriptions and webhooks handled safely
- A relational store with proper indexes and migrations
- Uses **Prisma** (see `src/`)
- Uses **Tailwind CSS** (see `src/`)

## Quick start

```bash
npm install
npm run dev
```

## Layout

- `src/nextjs_saas.tsx`
- `src/typescript_saas.ts`
- `src/stripe_saas.ts`
