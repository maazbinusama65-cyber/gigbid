# catalogue-search-facets

> typo-tolerant search box - repository for the retail engagement.

## Features

- Uses **Elasticsearch** (see `src/`)
- A component-based single-page interface with hooks
- Uses **Node.js** (see `src/`)
- Uses **PostgreSQL** (see `src/`)

## Quick start

```bash
npm install
npm run dev
```

## Layout

- `src/elasticsearch_catalogue.ts`
- `src/react_catalogue.tsx`
- `src/nodejs_catalogue.ts`
