# model-demo-web-app

> front end for a data science model - repository for the start-up engagement.

## Features

- Uses **FastAPI** (see `src/`)
- Uses **React** (see `src/`)
- Uses **Python** (see `src/`)
- Uses **TypeScript** (see `src/`)
- Containerised builds that run the same on every machine

## Quick start

```bash
npm install
npm run dev
```

## Layout

- `src/fastapi_model.py`
- `src/react_model.tsx`
- `src/typescript_model.ts`
