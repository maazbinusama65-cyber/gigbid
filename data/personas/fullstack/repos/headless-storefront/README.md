# headless-storefront

> catalogue and checkout rebuild - repository for the e-commerce engagement.

## Features

- Server-rendered React pages with route-level data fetching
- A typed schema stitched over several backends
- Card payments, subscriptions and webhooks handled safely
- A consistent look without hand-written stylesheets
- Strictly typed JavaScript across client and server

## Quick start

```bash
npm install
npm run dev
```

## Layout

- `src/nextjs_headless.tsx`
- `src/graphql_headless.ts`
- `src/stripe_headless.ts`
