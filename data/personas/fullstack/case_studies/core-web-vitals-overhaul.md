# Core Web Vitals Overhaul

**Client industry:** Digital agency  
**Completed:** 2024-04  
**Role:** sole engineer, from first call to hand-over

## The problem

The client had a familiar pain: marketing pages failed Core Web Vitals and lost ad quality score. They described what they wanted as a page speed rescue.

## What I built

I used Next.js for this part.
It relied on a component-based single-page interface with hooks.
This is where TypeScript came in.
I used Tailwind CSS for this part.

## Outcome

Result: LCP 4.1 s to 1.4 s; organic sessions +17% in two months.
