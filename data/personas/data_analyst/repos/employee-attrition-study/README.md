# employee-attrition-study

> HR turnover drivers - repository for the human resources engagement.

## Features

- Uses **regression analysis** (see `src/`)
- Reproducible notebooks in the statistician's language
- Uses **statistics** (see `src/`)
- A published workbook with filters and calculated fields

## Quick start

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m src.main
```

## Layout

- `src/regression_employee.py`
- `src/r_lang_employee.R`
- `src/statistics_employee.py`
