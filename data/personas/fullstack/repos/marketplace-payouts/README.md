# marketplace-payouts

> seller earnings transfers - repository for the online marketplace engagement.

## Features

- A hosted payments provider with signed event callbacks
- A minimal routing layer with middleware for auth and logging
- A relational store with proper indexes and migrations
- Shared type definitions between front end and back end

## Quick start

```bash
npm install
npm run dev
```

## Layout

- `src/stripe_marketplace.ts`
- `src/express_marketplace.ts`
- `src/postgres_marketplace.sql`
