# sheets-reporting-automation

> scripted weekly emails from sheets - repository for the agency engagement.

## Features

- Uses **Google Sheets** (see `src/`)
- Triggers that mail a weekly summary from a sheet
- Uses **Excel** (see `src/`)

## Quick start

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m src.main
```
