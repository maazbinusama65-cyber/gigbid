# deployment-pipeline-revamp

> release process rescue - repository for the start-up engagement.

## Features

- Uses **GitHub Actions** (see `src/`)
- Containerised builds that run the same on every machine
- Infrastructure on a major public cloud with least-privilege roles
- Uses **Playwright** (see `src/`)

## Quick start

```bash
npm install
npm run dev
```
