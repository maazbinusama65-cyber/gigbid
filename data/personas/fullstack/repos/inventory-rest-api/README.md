# inventory-rest-api

> SKU tracking backend - repository for the logistics engagement.

## Features

- A batteries-included Python web framework with an admin site
- Uses **REST API design** (see `src/`)
- Uses **PostgreSQL** (see `src/`)
- A reproducible image with a one-command local start
- Scripts and services in a typed, tested codebase

## Quick start

```bash
npm install
npm run dev
```

## Layout

- `src/django_inventory.py`
- `src/rest_api_inventory.ts`
- `src/postgres_inventory.sql`
