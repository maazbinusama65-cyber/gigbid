# dynamic-pricing-experiments

> discount elasticity study - repository for the travel engagement.

## Features

- Split tests read out with confidence intervals
- Uses **scikit-learn** (see `src/`)
- Uses **pandas** (see `src/`)
- Uses **SQL** (see `src/`)

## Quick start

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m src.main
```

## Layout

- `src/pandas_dynamic.py`
