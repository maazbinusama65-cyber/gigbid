# customer-survey-nps

> feedback themes report - repository for the hospitality engagement.

## Features

- Uses **survey analysis** (see `src/`)
- Uses **R** (see `src/`)
- Careful inference instead of eyeballing charts
- Publication-quality statistical charts from code

## Quick start

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m src.main
```

## Layout

- `src/survey_analysis_customer.py`
- `src/r_lang_customer.R`
- `src/statistics_customer.py`
