# Model Demo Web App

**Client industry:** Start-up  
**Completed:** 2023-09  
**Role:** sole engineer, from first call to hand-over

## The problem

The client had a familiar pain: a data science team had a notebook but no way to show clients. They described what they wanted as a interactive predictions page.

## What I built

We ended up with a typed async HTTP service with auto-generated docs.
We ended up with an interactive front end split into reusable components.
We ended up with a set of small automation tools.
We ended up with shared type definitions between front end and back end.
This is where Docker came in.

## Outcome

Result: client demos moved from notebooks to a shareable page; 3 pilot customers signed.
