# regional-sales-kpi-dashboard

> area manager performance view - repository for the retail engagement.

## Features

- A published workbook with filters and calculated fields
- Reporting queries over millions of rows
- Uses **KPI dashboards** (see `src/`)
- Advanced spreadsheet models with lookups and pivot tables

## Quick start

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m src.main
```

## Layout

- `src/tableau_regional.sql`
- `src/sql_regional.sql`
- `src/kpi_dashboards_regional.sql`
