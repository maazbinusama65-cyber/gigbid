# graphql-api-gateway

> API consolidation layer - repository for the media engagement.

## Features

- A single query endpoint where clients pick the fields they need
- Backend services written in server-side JavaScript
- Uses **TypeScript** (see `src/`)
- Uses **Redis** (see `src/`)

## Quick start

```bash
npm install
npm run dev
```

## Layout

- `src/graphql_graphql.ts`
- `src/nodejs_graphql.ts`
- `src/typescript_graphql.ts`
