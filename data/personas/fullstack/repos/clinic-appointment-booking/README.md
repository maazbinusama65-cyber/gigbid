# clinic-appointment-booking

> online slots and reminders - repository for the healthcare engagement.

## Features

- A component-based single-page interface with hooks
- A batteries-included Python web framework with an admin site
- Uses **PostgreSQL** (see `src/`)
- Long jobs pushed off the request path into a retrying worker pool
- Uses **JWT authentication** (see `src/`)

## Quick start

```bash
npm install
npm run dev
```

## Layout

- `src/react_clinic.tsx`
- `src/django_clinic.py`
- `src/postgres_clinic.sql`
