# realtime-support-chat

> in-app agent inbox - repository for the saas engagement.

## Features

- Uses **React** (see `src/`)
- A JavaScript server process handling concurrent requests
- Uses **WebSockets** (see `src/`)
- A fast key-value layer for sessions and rate limits
- Shared type definitions between front end and back end

## Quick start

```bash
npm install
npm run dev
```

## Layout

- `src/react_realtime.tsx`
- `src/nodejs_realtime.ts`
- `src/websockets_realtime.ts`
