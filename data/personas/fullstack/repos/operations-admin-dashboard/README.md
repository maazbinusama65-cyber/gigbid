# operations-admin-dashboard

> order management console - repository for the logistics engagement.

## Features

- A component-based single-page interface with hooks
- Uses **TypeScript** (see `src/`)
- A documented HTTP interface other teams could build against
- A consistent look without hand-written stylesheets
- Uses **Playwright** (see `src/`)

## Quick start

```bash
npm install
npm run dev
```

## Layout

- `src/react_operations.tsx`
- `src/typescript_operations.ts`
- `src/rest_api_operations.ts`
