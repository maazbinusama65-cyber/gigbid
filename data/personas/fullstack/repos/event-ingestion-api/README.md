# event-ingestion-api

> clickstream collector - repository for the ad tech engagement.

## Features

- Schemaless collections with TTL indexes
- Uses **Express** (see `src/`)
- Backend services written in server-side JavaScript
- Containerised builds that run the same on every machine
- Cloud hosting with managed queues, storage and load balancing

## Quick start

```bash
npm install
npm run dev
```

## Layout

- `src/mongodb_event.ts`
- `src/express_event.ts`
- `src/nodejs_event.ts`
