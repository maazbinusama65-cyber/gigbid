# crm-data-cleanup

> messy customer list rescue - repository for the b2b services engagement.

## Features

- Uses **data cleaning** (see `src/`)
- Scripts and services in a typed, tested codebase
- Tabular wrangling in dataframes with merges and group-bys
- Uses **Excel** (see `src/`)

## Quick start

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m src.main
```
