# Headless Storefront

**Client industry:** E-commerce  
**Completed:** 2023-08  
**Role:** sole engineer, from first call to hand-over

## The problem

The client had a familiar pain: the template store was slow and hard to customise. They described what they wanted as a fast custom shop front-end.

## What I built

Next.js did the heavy lifting here.
This is where GraphQL came in.
I set up a hosted payments provider with signed event callbacks.
We ended up with a consistent look without hand-written stylesheets.
We ended up with strictly typed JavaScript across client and server.

## Outcome

Result: mobile conversion up 19% and LCP from 4.8 s to 1.6 s.

## Stack

Next.js, GraphQL
