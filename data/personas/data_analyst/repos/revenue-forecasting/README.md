# revenue-forecasting

> seasonal sales outlook - repository for the saas engagement.

## Features

- Projections that finance used in budget talks
- A set of small automation tools
- Careful inference instead of eyeballing charts
- Advanced spreadsheet models with lookups and pivot tables

## Quick start

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m src.main
```

## Layout

- `src/forecasting_revenue.py`
- `src/statistics_revenue.py`
