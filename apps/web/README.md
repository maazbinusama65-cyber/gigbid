# GigBid web (Vite + React + TypeScript, strict)

```
src/app/         routes: SignIn, Onboarding, Inbox, JobDetail (jobs/:id), Studio (studio/:id), Approvals,
                 Pipeline, Messages, Runs + RunViewer (runs/:id), Analytics, Settings
src/components/  EvidenceHover, ApprovalPanel, DecisionControls, Diff, RunTimeline, RequirementMatrix,
                 RiskBadges (Badges.tsx), PipelineBoard, DegradedBanner, States (loading/empty/error)
src/lib/api/     GENERATED by `npm run gen:api` from FastAPI's OpenAPI (do not edit)
src/lib/         thin fetch wrapper (client.ts), SSE reader (sse.ts), react-query hooks (queries.ts)
tests/e2e/       Playwright specs
```

## Commands (from `apps/web`)

```bash
npm install
npm run gen:api       # python -m apps.api.export_openapi -> openapi.json -> src/lib/api/schema.d.ts
npm run dev           # http://localhost:5173, proxies /api to http://127.0.0.1:8000
npm run build         # tsc --noEmit && vite build
npx playwright install chromium
npm run test:e2e      # starts the API (mock mode, fresh sqlite) and the dev server itself
npm run report        # opens playwright-report/index.html
SCREENSHOTS=1 npx playwright test screenshots   # regenerates ../../docs/screenshots/*.png
```

The e2e suite uses the reviewer account `reviewer@gigbid.test` / `e2e-reviewer-pass`, seeded by
`scripts/start-api-e2e.mjs` (test-only values). Set `VITE_API_PROXY` to point the dev server elsewhere.
