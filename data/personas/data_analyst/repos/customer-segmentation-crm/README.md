# customer-segmentation-crm

> who-are-our-buyers clusters - repository for the retail engagement.

## Features

- Uses **customer segmentation** (see `src/`)
- A set of small automation tools
- Tabular wrangling in dataframes with merges and group-bys
- A governed report pack with scheduled refresh and row-level access

## Quick start

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m src.main
```

## Layout

- `src/customer_segmentation_customer.py`
- `src/pandas_customer.py`
