# marketing-attribution-model

> channel ROI breakdown - repository for the e-commerce engagement.

## Features

- Uses **SQL** (see `src/`)
- Uses **BigQuery** (see `src/`)
- A link-shared report that refreshes itself
- Uses **statistics** (see `src/`)
- Uses **Python** (see `src/`)

## Quick start

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m src.main
```
