# staff-portal-sso

> Google and Microsoft sign-in integration - repository for the education engagement.

## Features

- Delegated login via an identity provider
- Login sessions carried in short-lived signed tokens
- Backend services written in server-side JavaScript
- Uses **PostgreSQL** (see `src/`)

## Quick start

```bash
npm install
npm run dev
```

## Layout

- `src/oauth_staff.ts`
- `src/jwt_auth_staff.ts`
- `src/nodejs_staff.ts`
