# competitor-price-scraper

> daily shelf price tracker - repository for the e-commerce engagement.

## Features

- Uses **web scraping** (see `src/`)
- A set of small automation tools
- Uses **pandas** (see `src/`)
- A relational store with proper indexes and migrations

## Quick start

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m src.main
```

## Layout

- `src/web_scraping_competitor.py`
- `src/pandas_competitor.py`
- `src/postgres_competitor.sql`
