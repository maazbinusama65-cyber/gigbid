# browser-test-automation

> release safety net - repository for the fintech engagement.

## Features

- End-to-end regression runs across three browsers
- Fast unit tests with mocks and snapshot checks
- Push-triggered build, test and deploy workflows
- Shared type definitions between front end and back end

## Quick start

```bash
npm install
npm run dev
```

## Layout

- `src/playwright_browser.ts`
- `src/jest_browser.ts`
- `src/github_actions_browser.yml`
