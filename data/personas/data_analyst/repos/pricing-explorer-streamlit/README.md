# pricing-explorer-streamlit

> scenario modelling web tool - repository for the retail engagement.

## Features

- Uses **Streamlit** (see `src/`)
- Uses **Python** (see `src/`)
- Uses **pandas** (see `src/`)
- Uses **forecasting** (see `src/`)

## Quick start

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m src.main
```

## Layout

- `src/streamlit_pricing.py`
- `src/pandas_pricing.py`
- `src/forecasting_pricing.py`
