# Test Automation Suite

**Client industry:** Fintech  
**Completed:** 2024-02  
**Role:** sole engineer, from first call to hand-over

## The problem

The client had a familiar pain: regressions reached production after every release. They described what they wanted as a browser regression checks.

## What I built

Under the hood: Playwright.
On the engineering side I put in place fast unit tests with mocks and snapshot checks.
This is where GitHub Actions came in.
Under the hood: TypeScript.

## Outcome

Result: 180 unit and 35 browser tests; escaped bugs down 70%.

## Stack

Playwright, GitHub Actions, TypeScript
