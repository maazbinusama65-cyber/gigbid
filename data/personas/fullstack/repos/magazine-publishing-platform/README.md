# magazine-publishing-platform

> magazine back office - repository for the media engagement.

## Features

- Uses **Supabase** (see `src/`)
- Uses **Next.js** (see `src/`)
- Shared type definitions between front end and back end
- A consistent look without hand-written stylesheets

## Quick start

```bash
npm install
npm run dev
```

## Layout

- `src/supabase_magazine.ts`
- `src/nextjs_magazine.tsx`
- `src/typescript_magazine.ts`
